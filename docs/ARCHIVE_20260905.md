# Archive Notes: 2026-09-05

## Source Scope

This snapshot was assembled from `/mnt/data/yangky/test` on sys01. It preserves
the local uncommitted T800 implementation without committing or resetting any
source working tree.

- `whole_body_tracking/` contains the modified and newly added WBT files.
- `GMR/` contains the modified retargeting code and local robot assets already
  maintained in this combined repository.
- `engineai_native_sdk_integration/` contains overlays and `git apply` patches
  for both the development and deployment SDK working trees.
- `isaaclab_integration/` contains the small local IsaacLab delta.
- `results/t800_canonical_v1_20260902/` contains the reproducible data products.

Exact base revisions and upstream URLs are in `manifests/repositories.json`.

## Asset Policy

The archive includes:

- all six approved canonical references and their conversion intermediates;
- every training and evaluation report in the canonical qualifier state;
- the last checkpoint from each of 26 reported training rounds;
- accepted PT and ONNX policies plus the official EngineAI recovery MNN;
- all T800 policy renders, reference audits, and artifact videos present at the
  time of archival;
- compressed copies of the full canonical training logs, GMR work outputs, and
  official recovery robustness/visual experiments.

It excludes 34 GB of repeated every-100-step checkpoints, third-party Git
histories, build outputs, virtual environments, and simulator caches. These are
not unique project results and can be reproduced from the recorded repositories
and final checkpoints.

## Integrity

`results/t800_canonical_v1_20260902/SHA256SUMS` covers every result file other
than the checksum file itself. Verify with:

```bash
cd results/t800_canonical_v1_20260902
sha256sum -c SHA256SUMS
```

Compressed archives use tar plus Zstandard:

```bash
tar --zstd -xf archives/canonical_training_logs.tar.zst
```

## Safety Status

Only manifests in `qualification/best/` are accepted. In particular, all
spinning-kick checkpoints and videos are diagnostic assets. The joint
stand/action/stand policy was not started because one of five standing motions
failed its prerequisite gate.
