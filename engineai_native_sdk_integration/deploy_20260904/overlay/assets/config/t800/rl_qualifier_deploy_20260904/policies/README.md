# Policy artifacts

- `t800_qualifier_joint_policy.onnx`: original training export, including trajectory-reference outputs.
- `t800_qualifier_joint_policy_actor.onnx`: extracted actor-only graph, `obs[1,140] -> actions[1,25]`.
- `t800_qualifier_joint_policy.mnn`: MNN 2.9.5 runtime artifact used by the T800 Runner.

The actor-only ONNX is generated by `tools/prepare_qualifier_policy.py` before MNN conversion.
